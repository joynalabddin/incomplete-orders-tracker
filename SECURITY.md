# Security Policy

## Supported versions

Security fixes are published through the public GitHub repository and versioned Releases. Please use the latest release whenever possible.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Contact Joynal Abdin through [devjoynal.com](https://devjoynal.com) with the affected version, a concise description, reproducible steps, and a safe way to follow up. Remove passwords, API keys, customer data and other secrets from all reports.

After a report is received, the issue will be assessed, reproduced where possible, fixed or mitigated, and documented in a release note when appropriate.
